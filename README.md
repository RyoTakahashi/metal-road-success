# Metal Road ~Success!~

パワプロ「栄冠ナイン」のゲームシステムを下敷きに、テーマを **社会人メタルバンド** に置き換えた育成シミュレーション。

- 設計仕様: [`docs/design.md`](docs/design.md)
- コアループ（意思決定→4KPI）の数式モデル: [`docs/core-loop.md`](docs/core-loop.md)

## 現在の状態：縦切りプロトタイプ (v0.1)

「**すごろくで1ヶ月を進行 → 月末ライブの意思決定 → 4KPI算出 → 次の月へ**」が一周回る最小プレイアブル。

実装済み：
- すごろく式進行ボード（進行カードで前進・体力消費・各マスのイベント）
- メンバー4人（Vo/Gt/Ba/Dr）の能力ゲージ＆体力（パワプロ風UI）
- 練習でのパラメータ成長（経験点→能力アップ）
- 月末ライブの意思決定（会場キャパ／ターゲット層／楽曲）
- `core-loop.md` 準拠のKPI計算（動員・満足度・新規ファン・ストリーミング・収支）

未実装（今後）：契約更新、複数楽曲の作成、フェス/タイアップの専用フロー、サブジャンル適性、セーブ。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 型チェック + 本番ビルド (dist/)
npm run preview  # ビルド結果をプレビュー
```

## 技術スタック

- Vite + TypeScript（フレームワークなし、DOM + CSSでパワプロ風UI）
- ゲームロジックは `src/game/`（`coreLoop.ts` がKPIモデルの実体）、描画は `src/ui/`
