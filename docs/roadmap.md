# 開発ロードマップ（フィードバック反映 v0.2）

プレイヤーの立場は **バンドのリーダー＝活動の意思決定者**。本書は 2026-07 のレビュー
フィードバックを、テーマ別に優先度・依存関係・想定工数で整理したもの。数値/バランスは
すべて暫定（`core-loop.md` の `【K】` と同様、後段でチューニング）。

凡例：優先度 ★（高）／☆（中）／·（低）、工数 S/M/L。

---

## A. グラフィック
- **A1**〔·／M〕各キャラのビジュアルに選択肢（衣装・髪型バリエ）。DNA/プロンプトを
  バリアント対応にして `assets.ts` を差分キーで拡張。
- **A2**〔済〕スマホでの立ち絵とメッセージ窓の重複解消（<640px で縦積み）。→ 実装済み。
  - 残課題：4人シーンはモバイルで中央2人しか収まらない（横はみ出し）。要「人数で縮小」対応。

## B. サウンド
- **B1**〔実装済〕進行度連動BGM。`src/ui/audio.ts` で1曲ずつループ再生（遅延ロード）。
  マッピング：タイトル/パート選択=`metal-road`／ボード=月で進行（`rolling-dice`→3ヶ月〜
  `isolated-cosmos`→6ヶ月〜`metropolis`）／ライブ=`crimson-horizon`／結果=`freedom`。
  右下にミュートトグル（localStorage保存）。曲の割当は `main.ts` の `applyBgm()` で変更可。
- **B2**〔☆／M〕メタルSE：選択・イベント時にシャウト／ブリッジミュート2〜3音／
  ピッキングハーモニクス1音 等。UI操作音とイベント演出音を分けて設計。

## C. システム／UI（進行の作り替え）
- **C1**〔★／M〕プレイヤー＝リーダー化。**パート選択**（Vo/Gt/Ba/Dr…）を可能に。
  自分のパートに応じて初期能力や一部イベントが変化。
- **C2**〔★／L〕進行を「**完全ランダム→半ランダムの選択カード制**」へ。毎ターン提示される
  行動カードから選ぶ：
  - **常時選択可**：①休息（完全休養／社会勉強／趣味）
  - **半ランダムで出現**：②音楽活動（作曲／練習／パフォーマンス）③広報活動
    ④関係性構築（バンド関係者／新たな人脈）⑤アルバイト
  - 現在のサイコロ式ボードは、この「カード提示」を内包する形に再設計。

## D. 戦略性（コアループ拡張）
- **D1**〔一部済／M〕**休息の必然性**。体力平均が閾値(25)未満で**休息以外の行動が不可**に
  （疲労ロック実装済み）。残：体力枯渇での風邪・不調やドラッグ乱用疑惑等のマイナスイベント。
- **D2**〔★／S〕**序盤の資金ゲート**。ライブ開催に必要な金額をバイトで捻出する導入
  （バランス別途）。「やりたいけど先に稼ぐ」緊張感。
- **D3**〔★／M〕**継続性の要求**。新曲を数ヶ月に一度出さないと知名度/ファンが伸びない。
  練習を定期的にしないとライブ質が落ち、広報の如何に関わらずファンが減る（増えない）。
- **D4**〔☆／M〕**効果的施策の段階変化**。序盤は対バンが効く、メジャーデビュー後は
  企業案件が効く（いずれも「新たな人脈形成」の成果として解禁）。
- **D5**〔☆／L〕**サポートメンバー追加**（メジャーデビュー前後）。メリット：活動規模・
  選択肢拡大。デメリット：利益分散・人間関係の複雑化。前提として人脈が必要。
- **D6**〔☆／L〕**プロデューサー／レコード会社**。各ターンの選択カードが増える一方、
  規模拡大・ブランディングの外圧がかかる（方針が合わなければ離反もあり得る）。
- **D7**〔☆／M〕**PA／ローディー**でライブ品質↑。ただし十分な効果には**親密度**が必要で、
  一定値以下だと当日トラブルや後日の喧嘩イベント等のペナルティ。
- **D8**〔·／M〕**社会からの外圧パラメータ**。社会情勢の変化でファン増減、社会風刺で
  コア層を獲得 等。ファン/候補層を外部環境と連動させる。

## 依存関係と提案フェーズ

```
C1 パート選択 ─┐
C2 選択カード制 ┼─→ D3 継続性 ─→ D4 施策の段階変化 ─→ D5/D6 サポート&プロデューサー
D2 資金ゲート ─┘                         │
                                         └─→ D7 PA/ローディー親密度
D1 休息ペナルティ ── C2 に付随
D8 社会外圧 ── 後半（ファン系が固まってから）
B1/B2 サウンド, A1 ビジュアル選択 ── 独立（いつでも差し込み可）
```

- **Phase 1（骨格の作り替え）**：C1 + C2 + D2 + D3
  → 「毎ターン意味のある選択」「稼ぐ→活動→ライブ」「継続しないと落ちる」を成立させる。
  ここが全ての土台。ゲームとして一番化ける。
- **Phase 2（関係性システム）**：C2④人脈 + D5 + D6 + D7
  → 人脈→サポート追加→外圧/親密度、という中盤の駆け引き。
- **Phase 3（世界観・変化）**：D4 + D8 + D1
  → 段階変化・社会外圧・休息ペナルティで長期戦略に厚みを。
- **Phase 4（演出の締め）**：B1 + B2 + A1
  → BGM/SE/ビジュアル選択で“ゲームらしさ”を仕上げ。独立作業なので随時並行可。

> 補足：Phase 1 は既存の `state.ts`（ボード生成）・`coreLoop.ts`（KPI）・`narrative.ts`
> （シーン）を大きく触る。まず設計メモ（型と状態の変更点）を固めてから着手するのが安全。

## Phase 2 進捗（関係性システム）
- **P2-0 メジャーデビュー段階**〔済〕`state.rank: "indie"|"major"`。ファン≥3000 かつ 知名度≥40 で
  月初にデビューイベント発火→`major`化。トップバーに INDIE/MAJOR チップ。メジャーで大箱
  （500/1200/2500）解禁。今後 D5/D6 の解禁条件に使用。
- **P2-1 人脈/結束 基盤**〔済〕`contacts`（人脈）・`bond`（結束）を追加。新たな人脈→人脈+、
  バンド関係者→結束+（月初回復↑）。ボードにメーター表示。
- **P2-2 サポートメンバー**〔済〕`state.staff`。メジャー＆人脈で「関係性構築→サポート勧誘」
  から招致（枠3）。ライブ収益から人件費（cut）を天引き＝利益分散。親密度メーター。
- **P2-3 プロデューサー/レコード会社**〔済〕在籍で手札+1・作曲Q↑。ただし小箱続きだと
  親密度が下がる外圧、0で離脱。
- **P2-4 PA・ローディー＋親密度**〔済〕PAでライブ満足度↑（親密度<40でトラブル→満足度減）、
  ローディーで体力消費軽減＆トラブル半減。親密度は「バンド関係者」で上昇、月ごとに自然減衰、
  0で離脱。

## 進行・関門システム（ゲームオーバー / クリア）
プレイヤー＝リーダーの「登竜門→フェス→メジャー→大型フェス→海外進出」の関門ラダー。
各関門に**到達条件**と**期限（月）**があり、期限までに条件（演奏力=T/P/S/V平均・ファン・曲数・
結束・知名度）を満たせば進行、間に合わなければ**解散＝ゲームオーバー**。海外進出＝クリア。
- ボードに常時「次の関門／期限までの残り月・行動数／条件チェックリスト」を表示。
- 既存の自動メジャーデビュー(P2-0)はメジャー関門に統合（達成で `rank=major`）。
- ゲームオーバー画面／クリア画面（ともに「もう一度はじめる」でリスタート）。
- 実装済み。デフォルト閾値/期限は暫定（`MILESTONES` in state.ts、バランスで調整）。

### アイテム〔実装済〕
- 全13種（`ITEMS` in state.ts、Excelラインナップ準拠）。インベントリ（description＋effect表示）、
  **使用はターン非消費**。ボード／ライブ画面から使用可。
- ドロップ：各行動後30%→Tier抽選（S2%/A18%/B80%）→同Tier等確率。**Conditionは出現条件**
  （血まみれ/星の弦/メタルゴッドの証は条件を満たすまで抽選プールから除外）。開始 メタリアンD×2。
- 一時バフ枠（`GameState.buffs`）：練習倍率（ターン数付き）／休息全回復／作曲Q95／
  次ライブ満足度・満員。能力付与は全員。
- 残：レア度に応じた発見演出の差別化、所持上限（現状は無制限）など。

## 発言選択イベント / 愛情度〔実装済〕
- **愛情度**（`Member.love` 0–100、初期30）：リーダーと各メンバーの関係性。メンバーパネルでハート表示。
- **発言選択**：一部イベントで、シーン内にリーダーの返答ボタンが出る（`Scene.choices`）。選択で
  効果（結束・体力・資金・能力の小変動）と相手の**愛情度**が変わり、性格に応じた反応が返る。
  - 「関係性構築＞バンド関係者」＝毎回インタラクティブな語らい（`bondTalkScenes`）。
  - ターン開始時 ~28% で、いずれかのメンバーが個別に話しかけてくる小イベント（`maybeMemberEvent`、
    `MEMBER_EVENTS`。リーダー本人は対象外）。
- **見返り**：平均愛情度がライブ満足度を最大+8底上げ（`K.loveSatCoef`、暫定・調整可）。
- **友情イベント**〔実装済〕：愛情度が閾値（`FRIENDSHIP_THRESHOLD`=70）に達したメンバーごとに
  1回だけ特別シーンが発火し、**永続の能力ボーナス+6＋結束+6**（`FRIENDSHIPS`/`pendingFriendshipScenes`）。
  ターン開始時に友情イベントを最優先で処理（`nextTurnEvent`）。
- **ライブ中のMC/パフォーマンス選択**〔実装済〕：ライブは**2ターン制**（本編→間奏MC→アンコール）。
  `buildLivePreScenes` で「本編MC第一声／ソロ回し／間奏MC／ラストソング締め」を選ぶ。
  - **ターゲット層＆相性**で効果が変動：各MC/締め選択は`favored`セグメントと`decision.target`が一致すると
    満足度ボーナス。ソロ回しは`SEG_WEIGHTS`で算出した**ターゲット最適メンバー**を指名すると加点（`segFit`/
    `bestSoloistKey`）。相性の良し悪しで反応（掛け合い）も分岐。
  - **飽き対策**：MC第一声／間奏MCは**各5パターン**（`LIVE_MC_SCRIPTS`/`LIVE_ENCORE_MC_SCRIPTS`）、
    打ち上げ会話も**5パターン**（`PARTY_SCRIPTS`）を用意し、**連続同一を回避**（`pickIdxNoRepeat`＋`state.recent`）。
  - 選択→ライブ解決→ライブ描写→結果の順（`main.ts` afterSlides="liveResolve"）。
- **練習中の発言選択**〔実装済〕：練習の約50%で、メンバーが手を止めて話しかけてくる（`practiceTalk`）。
  トピックは**メンバーごとの専用ネタ**（`PRACTICE_TOPICS_BY_MEMBER`、性格反映）。返答で愛情度・体力・能力が
  小変動＋反応。
- **選択の反応**：全ての発言選択（人脈交流・メンバーイベント・練習・ライブMC/ソロ・打ち上げ）で、
  選んだ項目に応じた専用リアクションと効果サマリを表示。
- **ライブ後の打ち上げ**〔実装済〕：結果画面の「次の月へ」で打ち上げイベント（`buildAfterPartyScenes`）。
  ライブの出来でトーンが変化し、返答で全員の愛情度・結束・体力が動く（afterSlides="month"→月送り）。
- 実装：`state.ts`（`buildTalk`/`BOND_TOPICS`/`MEMBER_EVENTS`/`FRIENDSHIPS`/`buildLivePreScenes`/
  `buildAfterPartyScenes`/`addLove`/`avgLove`/`nextTurnEvent`）、`main.ts`（`onChooseReply`・分岐挿入・
  `proceedMonth`）、`render.ts`（選択UI・ハート）、`coreLoop.ts`（満足度加点）。

## ストーリー / チュートリアル〔実装済〕
- **オープニング・モノローグ**：パート選択後、選んだリーダー（表示名反映）を主軸に、バンドへの
  憧れ・メジャーデビューの夢・日々の奮闘を描く導入。
- **チュートリアル**：各メンバーが「どの行動でどのステータスが伸びるか」を説明（練習→演奏力、
  作曲→曲数、パフォーマンス/広報→ファン・知名度、関係性→人脈・結束、バイト→資金、休息→体力、
  関門＝期限までに条件達成）。関門条件の満たし方が分かるようにした。
- **関門ごとの導入描写**：新しい関門が現れるたび（ゲーム開始時＆各関門クリア後）に、その関門が
  何か・期限・条件を提示し、主人公＋バンドでモチベーションを上げる描写を挿入。
- 実装：`buildOpeningScenes/buildTutorialScenes/buildMilestoneIntro/buildIntroSequence`（state.ts）。
